## 🚀 Installation

**Step 1 — Create your bot (2 min):**
1. Open Telegram → search **@BotFather**
2. Send `/newbot` → pick a display name & username
3. Copy the **token** it gives you

**Step 2 — Install in Termux:**

```bash
curl -fsSL https://raw.githubusercontent.com/v4zrashd/RASHDMegaBotTermuxx/main/install.sh | bash
```

Paste your token when asked (or skip and run `v4zmegabot --set-token` later).

**Step 3 — Run it:**

```bash
v4zmegabot
```

Keep Termux running (or use `termux-wake-lock`) and your bot stays online 24/7. Open your bot in Telegram and send `/start` 🎉

## 📋 Requirements

- **Termux** (from F-Droid)
- Android 7.0+, internet connection
- A bot token from [@BotFather](https://t.me/BotFather)

## 🗑️ Uninstall

```bash
curl -fsSL https://raw.githubusercontent.com/v4zrashd/RASHDMegaBotTermuxx/main/uninstall.sh | bash
```
